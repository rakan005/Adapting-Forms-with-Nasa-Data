# Authentic screenshots only

This directory intentionally contains **no screenshots** yet.

Capture the running project yourself (browser screenshot or device capture), and add accurately labeled files. Suggested optional names:

- `overview-desktop.png`: actual landing screen at a desktop viewport
- `comparison-demo.png`: actual Synthetic Demo comparison with the synthetic banner visible
- `mobile-input.png`: actual narrow-screen input wizard
- `live-evidence.png`: **only if** the actual Node.js Live mode successfully loads NASA POWER and provenance is visible

Check that screenshots contain no private data or personally identifiable information. Do not use a screenshot of the demo to imply NASA data were fetched. PNG/JPEG/WebP are all acceptable based on quality and file size; optimize real files only after capturing them.

Then update the [README Screenshots section](../../README.md#screenshots) with relative Markdown image links, for example:

```md
![Field Shift desktop preview showing Synthetic Demo](docs/screenshots/overview-desktop.png)
```

**The example above is an instruction, not an existing screenshot.**
