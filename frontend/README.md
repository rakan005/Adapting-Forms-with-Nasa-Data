## Crop Advisor frontend

This folder contains the complete static frontend source and its bundled soil salinity map assets.

- index.html — Arabic single-page application.
- soil-salinity-2016.json — map geometry and salinity values loaded by the page.
- soil-salinity-2016.png — map visual asset.

Serve this folder as a static site so the page and map assets share the same directory. The API origin is configured in the crop-advisor-api-base meta tag in index.html. Demo values are illustrative and are not live NASA observations.
