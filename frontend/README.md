# Crop Advisor Frontend

واجهة عربية RTL باستخدام React 18 وVite وTailwind CSS، متصلة بواجهة Spring Boot.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
cp .env.example .env
npm install
npm run dev
```

عدّل `VITE_API_BASE_URL` إلى عنوان الـ API. القيمة الافتراضية المحلية هي `http://localhost:8080`. لا تضع مفاتيح Gemini أو البريد الإلكتروني في الواجهة؛ يجب أن تبقى على الخادم.

## الإنتاج وGitHub Pages

```bash
npm run build
npm run preview
```

ملف `vite.config.js` مضبوط للنشر على `/Adapting-Forms-with-Nasa-Data/`. مسارات React تعمل مع مسارات الصفحة المنشورة، ويقوم Workflow بنسخ `index.html` إلى `404.html` لتدعم إعادة تحميل الروابط العميقة على GitHub Pages. قيمة عنوان API الإنتاجية يضبطها Workflow عبر `VITE_API_BASE_URL`.

## تسجيل الدخول

التسجيل يطلب الاسم الكامل والبريد ورقم الهاتف الاختياري، ثم رمز تحقق من 6 أرقام. تسجيل الدخول يستخدم البريد والرمز فقط. يجب ضبط خدمة إرسال البريد في الباك اند كي يصل الرمز فعليًا. الرمز صالح لمدة 10 دقائق ويُرفق رمز الجلسة تلقائيًا في الطلبات اللاحقة.

## الشاشات والوظائف

- لوحة متابعة المزارع والقرارات والتنبيهات والخطة الحالية.
- إدارة المزارع: إضافة، تعديل، حذف، بحث، مساحة بالدونم، اختيار الموقع على الخريطة، وملوحة مختبرية اختيارية.
- تحليل الأرض: اختيار المحاصيل، إنشاء توصية وحفظها، عرض الثقة والتغطية ومؤشرات المناخ والتحذيرات والاستبعادات.
- سجل القرارات وتسجيل الإجراء الزراعي.
- سجل المواسم، مع الإنشاء والحذف من API.
- مساعد دردشة ومنظم نص إلى مسودة؛ المسودة لا تُحفظ دون مراجعة.
- التنبيهات وتفضيلاتها، الاشتراكات، وتقرير قابل للطباعة أو الحفظ بصيغة PDF من نافذة الطباعة.

## اختبار يدوي سريع

1. شغّل Spring Boot محليًا، واضبط البريد التجريبي أو Resend في الخادم، ثم أنشئ حسابًا جديدًا وتحقق من الرمز.
2. أضف مزرعة، اختر موضعها على الخريطة، اكتب المساحة وتحقق من ظهورها في القائمة والتفاصيل.
3. افتح «تحليل الأرض»، اختر المزرعة وبعض المحاصيل، أنشئ التوصية، ثم تحقق من تفاصيلها وسجل القرار وإجراء المزارع.
4. أضف سجل موسم واحذفه، وتحقق من انعكاس التغيير في صفحة تفاصيل المزرعة.
5. جرّب المحادثة وتنظيم النص؛ إذا لم يُضبط Gemini سيعرض الخادم خطأ الخدمة غير المهيأة.
6. غيّر تفضيلات التنبيه، واختر خطة، ثم افتح التقرير واطبعه أو اختر «حفظ كـ PDF».
7. سجّل الخروج، وافتح رابطًا محميًا مباشرة، وتحقق من توجيهك لتسجيل الدخول. اختبر المظهر الداكن وعرض الهاتف.

## حدود بيانات النسخة الحالية

حزمة المناخ والمحاصيل في الباك اند بيانات تجريبية وليست رصدًا فعليًا من NASA. الملوحة الإقليمية تصنيف خريطة UNDP GeoHub لعام 2016 وليست قياسًا بوحدة dS/m. الأسعار وبوابة الدفع غير مهيأتين؛ اختيار خطة مدفوعة يبقى معلقًا ولا يخصم مبلغًا. تنبيهات الطقس حاليًا تُقيّم عند طلب توصية ولا تمثل إنذارًا طارئًا. تقسيم الأرض إلى قطع منفصلة غير مدعوم بنقاط النهاية الحالية؛ السجلات الموسمية تحفظ المحصول والتواريخ والحالة والإنتاج والملاحظات.
