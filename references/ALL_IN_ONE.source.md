## 0. ترتيب الأولوية لهاكاثون 48 ساعة
1. **NASA POWER** (بلا حساب، سهل، يعمل لأي نقطة) ← أساس المناخ.

# الميزات والنمذجة وعدم اليقين

## 1. المبدأ
ابدأ بـ **MCDA شفاف** (قواعد خبيرة + ميزات من الأقمار + أولويات المزارع) ثم أضف **Monte Carlo** لعدم اليقين. نموذج مفهوم يثق به المزارع أفضل من صندوق أسود. التنفيذ الجاهز: `scripts/mcda.py`.

## 2. توحيد الدقة (Harmonization)
1. حدّد **شبكة/وحدة تحليل**: نقطة الحقل (MVP) أو شبكة 250 م/1 كم.
2. حوّل كل طبقة بالتجميع المناسب: هطول = مجموع؛ حرارة/NDVI = متوسط؛ أقصى حرارة = أقصى؛ رطوبة = متوسط/وسيط.
3. خطوة زمنية موحدة: أسبوعية/شهرية/موسمية.
4. طبّق أقنعة الجودة (غيوم) قبل التجميع واحسب **نسبة المشاهدات الصالحة**.
5. وثّق كل خطوة وأثرها على عدم اليقين (خفض دقة Landsat، رفع دقة SMAP…).

## 3. الميزات المفسَّرة (features)
| الميزة | من | الاشتقاق (`scripts/features.py`) |
|---|---|---|
| هطول سنوي/موسمي ومعامل تباين | POWER/IMERG | مجموع شهري، CV بين السنوات |
| أيام حرارة فوق عتبة | POWER T2M_MAX | عدّ الأيام > عتبة (مثلاً 35°م ⚠ يُعدَّل حسب المحصول) |
| أيام صقيع | POWER T2M_MIN | عدّ الأيام ≤ 0°م |
| عواصف شديدة | POWER/IMERG | أيام هطول > 20 مم ⚠ عتبة محلية |
| فترات جفاف طويلة | هطول يومي | أطول تتابع أيام < 1 مم |
| عجز مائي تقريبي | هطول − ETo | ETo من Hargreaves/FAO-56 (يمكن من T2M_MAX/MIN + إشعاع) |
| أسابيع الأرض العارية | NDVI | عدد المشاهدات/الأسابيع بـ NDVI < عتبة (⚠ عتبة 0.2 مبدئية، عايرها) |
| سعة/ذروة الموسم | NDVI | ذروة NDVI وشهرها ← يكشف موسم النمو الفعلي |
| شذوذ NDVI/رطوبة | NDVI/GWETROOT | (قيمة − متوسط الفترة المناظرة)/الانحراف المعياري |
| انحدار/جريان | SRTM | انحدار % ← خطر تعرية |

## 4. معايير MCDA (مقترحة)
`water_saving` توفير الماء · `soil_building` بناء التربة/N/مادة عضوية · `erosion_control` تقليل التعرية والأرض العارية · `income` دخل/سوق/علف · `heat_risk` تقليل مخاطر الحرارة/الصقيع/الجفاف · (اختياري) `pest_break`, `labor_equipment`.

### الصيغة
```
S_j = Σ_i w_i · n_ij        (w مجموعها 1، n_ij ∈ [0,1] مُطبَّعة)
```
- درجات المحصول (1–5) في `crops.csv` = **افتراضات خبيرة** تُطبَّع إلى [0,1] وتُتوسَّط على التناوب (مع وزن للمدة).
- **تعديل مناخي**: نتيجة `water_saving` و`heat_risk` تُضبط بميزات المنطقة (مثلاً: كلما كبر العجز المائي زادت أهمية انخفاض الطلب المائي). هذا يربط NASA بالقرار فعلياً.
- **الأرض العارية**: كل موسم "fallow/غير مزروع" يرفع خطر التعرية بنسبته ويخفض `erosion_control`.

## 5. عدم اليقين (Monte Carlo) — ما يفعله `mcda.py`
1. اضطراب درجات المحاصيل (σ≈0.5 على مقياس 1–5 ⚠).
2. اضطراب الأوزان (Dirichlet حول أوزان المزارع) لقياس حساسية الأولويات.
3. اضطراب الميزات المناخية بنسبة مرتبطة بجودة البيانات (مثلاً ±10–25%).
4. المخرجات لكل استراتيجية: **المتوسط، P5–P95، احتمال أن تكون الأولى، ثبات الترتيب.**
5. **مستوى الثقة** (عالٍ/متوسط/منخفض) يجمع: ثبات الترتيب + اكتمال البيانات + تغطية NDVI الصالحة + دقة المصدر. اعرض القاعدة بوضوح، ولا تدّعِ احتمالات علمية دقيقة؛ هي حساسية لافتراضات وليست احتمال نجاح فعلي.

## 6. فصل مصادر المعرفة (إلزامي في الواجهة)
وسم كل معلومة: 🛰 **رصد** (NASA/غيره) · 🧮 **استنتاج النموذج** · 👤 **افتراض خبير/مزارع**. هذا يخدم Validity ويمنع الادعاء المبالغ.

## 7. المعايرة والتحقق
- قارن **هطول POWER** بمحطة محلية/ERA5/CHIRPS (انحياز، RMSE شهري).
- قارن **موسم NDVI المرصود** مع **تقويم المحصول الحالي** الذي أدخله المزارع (هل الذروة حيث نتوقع؟).
- اختبار منطقي: غيّر الأوزان ← هل الترتيب يتغير بشكل معقول؟ حدّ أقصى للمنزلق: زيادة الجفاف ← تتقدم الاستراتيجية المائية.
- **Backtest بسيط**: سنة جافة (مثلاً موجة حر/جفاف معروفة) ← هل كانت الاستراتيجية الحالية تحمل أكبر هشاشة؟ (Hindcast).
- لا تدّعِ توقع غلة دون بيانات غلال محلية.

## 8. تعلّم الآلة — متى؟
فقط إن توفرت بيانات تدريب حقيقية (غلال/تصنيف حقول). خيارات: تجميع (clustering) لمناطق الحقل بالميزات، غابة عشوائية لتصنيف الأرض العارية. وإلا فالقواعد الشفافة أفضل لهذا الوقت القصير. إن استُخدم ML فاشرح الميزات المهمة (feature importance).

## 9. سيناريوهات
منزلقات: هطول ±%، حرارة +°م. أعد حساب الميزات (عجز مائي، أيام حارة) ثم الدرجات. اعرضها كـ"اختبار إجهاد افتراضي" مُعلَّم بوضوح أنه ليس توقعاً مناخياً.

## 10. تشغيل السكربتات (مُختبرة على بيانات اصطناعية فقط، لا على بيانات NASA حية)

# قاعدة معرفة المحاصيل

الملف الفعلي: `assets/crops.csv`. هذا الملف يشرح منطقه وحدوده.

## ما في الجدول
| العمود | المعنى | مصدر القيمة |
|---|---|---|
| `kc_mid` | معامل المحصول منتصف الموسم (FAO-56) | FAO Irrigation & Drainage Paper 56، جدول 12 — **قيم تقريبية، راجعها** |
| `n_fixing` | يثبّت النيتروجين (1/0) | معرفة زراعية عامة (البقوليات) |
| `root_depth`, `water_demand`, `drought_tol`, `frost_tol`, `erosion_cover`, `organic_matter`, `forage_value`, `market_flex`, `pest_break` | درجات 1–5 (5 = أعلى/أفضل بحسب العمود) | **افتراضات خبيرة** — ليست قياسات. عدّلها مع مرشد زراعي محلي |
| `bare_season_penalty` | يُطبَّق على "fallow" فقط | افتراض |

كل صف مسوم بـ `source` (`FAO-56 approx` / `expert_assumption`). **لا تقدّم أي رقم منها للمزارع كحقيقة قياسية.**

## أدوار أنواع المحاصيل
- **بقوليات (حمص، عدس، فول، برسيم):** تثبّت N وتقلل السماد؛ تكسر دورات الأمراض الحبوبية.
- **محاصيل تغطية (فيتش/بيقية، شوفان شتوي، برسيم حجازي):** تقلل الأرض العارية والتعرية، تضيف مادة عضوية، لكنها قد تستهلك ماءً قبل المحصول التالي (ضمن الميزان المائي).
- **جذور عميقة (عباد الشمس، ذرة رفيعة، برسيم حجازي):** تكسر الطبقات المتصلبة وتحسن الترشيح.
- **مقاومة للجفاف (شعير، ذرة رفيعة، دخن، حمص):** تخفض الطلب المائي.
- **علفية (برسيم، شوفان، بيقية):** دخل/مرونة تسويق.
- **بور (fallow):** يحفظ ماءً أحياناً لكنه يرفع التعرية والأرض العارية.

## قواعد تناوب عملية (للاستعانة عند بناء الاستراتيجيات — تُراجع محلياً)
- تجنّب تكرار نفس العائلة النباتية متتالية (الحبوب بعد الحبوب ← أمراض/أعشاب مرافقة).
- ضع بقولية قبل محصول مستهلك للنيتروجين.
- تدرّج الجذور (عميق ثم ضحل) يحسّن البنية.
- لا تضع محصولاً عالي الطلب المائي في منطقة شحيحة دون مصدر ري مضمون.
- جرّب الاستراتيجية الجديدة على **10–20% من المساحة** أولاً (نصيحة تجريبية شائعة، لا قاعدة رسمية).

#!/usr/bin/env python3
"""Derive interpretable seasonal features from POWER daily data and (optionally) NDVI.

Usage:
  python features.py --power power.csv [--ndvi ndvi.csv] --out features.json
        [--heat-thr 35] [--storm-mm 20] [--bare-ndvi 0.2]

Output JSON (consumed by mcda.py):
  aridity (0..1)   : mean annual water deficit (rain - ETo) scaled; 1 = very dry
  heat_index (0..1): mean hot days per year / 60
  rain_cv, frost_days, storm_days, longest_dry_spell, bare_share (if NDVI), data_quality (0..1)

ETo uses Hargreaves-Samani (needs T2M, T2M_MAX, T2M_MIN, latitude) - a rough estimate.
All thresholds are starting points: calibrate locally.
"""
import argparse, json, math
import numpy as np
import pandas as pd


def hargreaves_eto(tmax, tmin, tmean, doy, lat_deg):
    """Daily reference ET (mm/day), Hargreaves-Samani with extraterrestrial radiation Ra (FAO-56 eq. 21)."""
    lat = math.radians(lat_deg)
    dr = 1 + 0.033 * np.cos(2 * math.pi * doy / 365)
    dec = 0.409 * np.sin(2 * math.pi * doy / 365 - 1.39)
    ws = np.arccos(np.clip(-np.tan(lat) * np.tan(dec), -1, 1))
    ra = (24 * 60 / math.pi) * 0.0820 * dr * (ws * np.sin(lat) * np.sin(dec) + np.cos(lat) * np.cos(dec) * np.sin(ws))
    ra_mm = 0.408 * ra
    return np.maximum(0.0023 * (tmean + 17.8) * np.sqrt(np.maximum(tmax - tmin, 0)) * ra_mm, 0)


def longest_run(mask):
    best = cur = 0
    for v in mask:
        cur = cur + 1 if v else 0
        best = max(best, cur)
    return best


def power_features(df, lat, heat_thr=35.0, storm_mm=20.0):
    df = df.copy()
    df["year"] = df.index.year
    full_years = [y for y, g in df.groupby("year") if g["PRECTOTCORR"].notna().mean() > 0.9]
    if not full_years:
        raise ValueError("no year with >90% valid precipitation")
    d = df[df["year"].isin(full_years)]
    rain_y = d.groupby("year")["PRECTOTCORR"].sum()
    eto = hargreaves_eto(d["T2M_MAX"].values, d["T2M_MIN"].values, d["T2M"].values, d.index.dayofyear.values, lat)
    d = d.assign(ETO=eto)
    eto_y = d.groupby("year")["ETO"].sum()
    deficit = (eto_y - rain_y).clip(lower=0)
    feats = {
        "years_used": [int(y) for y in full_years],
        "rain_mm_mean": float(rain_y.mean()),
        "rain_cv": float(rain_y.std(ddof=0) / rain_y.mean()) if rain_y.mean() > 0 else None,
        "eto_mm_mean": float(eto_y.mean()),
        "deficit_mm_mean": float(deficit.mean()),
        "heat_days_mean": float(d.groupby("year").apply(lambda g: (g["T2M_MAX"] > heat_thr).sum()).mean()),
        "frost_days_mean": float(d.groupby("year").apply(lambda g: (g["T2M_MIN"] <= 0).sum()).mean()),
        "storm_days_mean": float(d.groupby("year").apply(lambda g: (g["PRECTOTCORR"] > storm_mm).sum()).mean()),
        "longest_dry_spell_days": int(max(longest_run((g["PRECTOTCORR"] < 1).values) for _, g in d.groupby("year"))),
    }
    feats["aridity"] = float(np.clip(feats["deficit_mm_mean"] / 1200.0, 0, 1))  # 1200 mm: arbitrary scale
    feats["heat_index"] = float(np.clip(feats["heat_days_mean"] / 60.0, 0, 1))
    feats["power_completeness"] = float(d["PRECTOTCORR"].notna().mean())
    return feats


def ndvi_features(nd, bare_thr=0.2):
    nd = nd.copy()
    nd["date"] = pd.to_datetime(nd["date"])
    good = nd[(nd["reliability"].fillna(0) == 0) & nd["ndvi"].notna()] if "reliability" in nd else nd[nd["ndvi"].notna()]
    valid_share = len(good) / max(len(nd), 1)
    if good.empty:
        return {"ndvi_valid_share": 0.0, "bare_share": None}
    good = good.assign(bare=good["ndvi"] < bare_thr, month=good["date"].dt.month)
    by_month = good.groupby("month")["ndvi"].mean()
    return {
        "ndvi_valid_share": float(valid_share),
        "bare_share": float(good["bare"].mean()),
        "bare_months": [int(m) for m, v in by_month.items() if v < bare_thr],
        "ndvi_peak_month": int(by_month.idxmax()),
        "ndvi_peak": float(by_month.max()),
    }


def build(power_csv, lat, ndvi_csv=None, **kw):
    p = pd.read_csv(power_csv, parse_dates=["date"], index_col="date")
    feats = power_features(p, lat, kw.get("heat_thr", 35.0), kw.get("storm_mm", 20.0))
    dq = feats["power_completeness"]
    if ndvi_csv:
        nf = ndvi_features(pd.read_csv(ndvi_csv), kw.get("bare_ndvi", 0.2))
        feats.update(nf)
        dq = 0.6 * dq + 0.4 * nf["ndvi_valid_share"]
    feats["data_quality"] = float(round(dq, 3))
    return feats


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--power", required=True)
    ap.add_argument("--lat", type=float, required=True, help="latitude of the field (for ETo)")
    ap.add_argument("--ndvi")
    ap.add_argument("--out", default="features.json")
    ap.add_argument("--heat-thr", type=float, default=35.0)
    ap.add_argument("--storm-mm", type=float, default=20.0)
    ap.add_argument("--bare-ndvi", type=float, default=0.2)
    a = ap.parse_args()
    f = build(a.power, a.lat, a.ndvi, heat_thr=a.heat_thr, storm_mm=a.storm_mm, bare_ndvi=a.bare_ndvi)
    json.dump(f, open(a.out, "w"), indent=2, ensure_ascii=False)
    print(json.dumps(f, indent=2, ensure_ascii=False))
```

#!/usr/bin/env python3
"""Explainable MCDA + Monte Carlo uncertainty for crop-rotation strategies.

Usage:
  python mcda.py --crops ../assets/crops.csv --strategies ../assets/strategies.example.json \
                 [--features features.json] [--weights water_saving=0.4,income=0.1,...] \
                 [--n 3000] [--seed 1] [--out results.json]

Method (see references/modeling.md):
  1. Crop criterion scores (1-5, expert assumptions in crops.csv) -> normalised to [0,1].
  2. Strategy score per criterion = mean over the rotation's seasons.
  3. Climate adjustment: weights of water_saving / heat_risk are scaled up with the
     region's aridity / heat_index (from features.json), then renormalised.
  4. Monte Carlo: perturb crop scores (sd 0.5 on 1-5 scale), weights (Dirichlet), and
     climate features (relative noise grows as data_quality falls).
  5. Report mean, P5-P95, P(top) and a confidence label per strategy.

Outputs are SENSITIVITY to assumptions, not probabilities of real-world success.
"""
import argparse, json
import numpy as np
import pandas as pd

CRITERIA = ["water_saving", "soil_building", "erosion_control", "income", "heat_risk"]


def crop_criteria(c):
    """Map crop traits (1-5) to criterion scores (1-5). Higher = better."""
    return {
        "water_saving": 0.6 * (6 - c["water_demand"]) + 0.4 * c["drought_tol"],
        "soil_building": 0.4 * c["organic_matter"] + 0.3 * (5 if c["n_fixing"] else 1) + 0.3 * c["root_depth"],
        "erosion_control": c["erosion_cover"],
        "income": 0.5 * c["market_flex"] + 0.5 * c["forage_value"],
        "heat_risk": 0.5 * c["drought_tol"] + 0.5 * c["frost_tol"],
    }


def norm(x):
    return (x - 1.0) / 4.0


def strategy_matrix(crops, strat, noise=None, rng=None):
    """Returns array [criterion] of mean normalised scores for the strategy."""
    rows = []
    for name in strat["seasons"]:
        r = crops.loc[name]
        if noise:
            r = r.copy()
            for k in ("water_demand", "drought_tol", "organic_matter", "root_depth", "erosion_cover",
                      "market_flex", "forage_value", "frost_tol"):
                r[k] = float(np.clip(r[k] + rng.normal(0, noise), 1, 5))
        cc = crop_criteria(r)
        rows.append([norm(cc[k]) for k in CRITERIA])
    m = np.mean(rows, axis=0)
    # bare-field share penalises erosion control further (explicit, explainable rule)
    bare = np.mean([1.0 if crops.loc[n, "group"] == "fallow" else 0.0 for n in strat["seasons"]])
    m[CRITERIA.index("erosion_control")] *= (1 - 0.5 * bare)
    return m


def effective_weights(w, aridity, heat_index):
    w = np.array([w[k] for k in CRITERIA], dtype=float)
    w[CRITERIA.index("water_saving")] *= (1 + aridity)
    w[CRITERIA.index("heat_risk")] *= (1 + heat_index)
    return w / w.sum()


def run(crops, strategies, base_w, feats, n=3000, seed=1, crop_noise=0.5, conc=30.0):
    rng = np.random.default_rng(seed)
    dq = float(feats.get("data_quality", 0.7))
    ar0, he0 = float(feats.get("aridity", 0.5)), float(feats.get("heat_index", 0.3))
    rel_noise = 0.10 + 0.25 * (1 - dq)  # 10%..35% depending on data quality
    base = np.array([base_w[k] for k in CRITERIA]); base = base / base.sum()

    det = {}
    w0 = effective_weights(dict(zip(CRITERIA, base)), ar0, he0)
    for s in strategies:
        m = strategy_matrix(crops, s)
        det[s["id"]] = {"score": float(m @ w0), "criteria": dict(zip(CRITERIA, np.round(m, 3).tolist()))}

    sims = {s["id"]: np.empty(n) for s in strategies}
    top = {s["id"]: 0 for s in strategies}
    ids = [s["id"] for s in strategies]
    for i in range(n):
        w = rng.dirichlet(base * conc + 1e-6)
        ar = float(np.clip(ar0 * (1 + rng.normal(0, rel_noise)), 0, 1))
        he = float(np.clip(he0 * (1 + rng.normal(0, rel_noise)), 0, 1))
        we = effective_weights(dict(zip(CRITERIA, w)), ar, he)
        vals = {s["id"]: float(strategy_matrix(crops, s, crop_noise, rng) @ we) for s in strategies}
        for k, v in vals.items():
            sims[k][i] = v
        top[max(vals, key=vals.get)] += 1

    out = []
    for s in strategies:
        a = sims[s["id"]]
        p5, p95 = np.percentile(a, [5, 95])
        width = float(p95 - p5)
        conf = "high" if (width < 0.10 and dq >= 0.7) else "medium" if width < 0.20 else "low"
        out.append({
            "id": s["id"], "name": s["name"], "seasons": s["seasons"], "why": s.get("why", ""),
            "score_deterministic": round(det[s["id"]]["score"], 4),
            "mean": round(float(a.mean()), 4), "p5": round(float(p5), 4), "p95": round(float(p95), 4),
            "p_top": round(top[s["id"]] / n, 3), "confidence": conf,
            "criteria": det[s["id"]]["criteria"],
        })
    out.sort(key=lambda r: r["mean"], reverse=True)
    return {"data_quality": dq, "effective_weights_at_features": dict(zip(CRITERIA, np.round(w0, 3).tolist())),
            "ranking_stability_top1": out[0]["p_top"], "strategies": out,
            "caveat": "Sensitivity to assumptions, not probability of success. Review locally."}


def parse_weights(txt, defaults):
    w = dict(defaults)
    if txt:
        for kv in txt.split(","):
            k, v = kv.split("="); w[k.strip()] = float(v)
    return w


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--crops", required=True)
    ap.add_argument("--strategies", required=True)
    ap.add_argument("--features")
    ap.add_argument("--weights")
    ap.add_argument("--n", type=int, default=3000)
    ap.add_argument("--seed", type=int, default=1)
    ap.add_argument("--out", default="results.json")
    a = ap.parse_args()
    crops = pd.read_csv(a.crops).set_index("crop")
    sj = json.load(open(a.strategies))
    feats = json.load(open(a.features)) if a.features else {"aridity": 0.5, "heat_index": 0.3, "data_quality": 0.5}
    missing = {c for s in sj["strategies"] for c in s["seasons"]} - set(crops.index)
    if missing:
        raise SystemExit(f"unknown crops in strategies: {sorted(missing)}")
    res = run(crops, sj["strategies"], parse_weights(a.weights, sj["weights"]), feats, a.n, a.seed)
    json.dump(res, open(a.out, "w"), indent=2, ensure_ascii=False)
    for r in res["strategies"]:
        print(f"{r['id']:18s} mean={r['mean']:.3f} [{r['p5']:.3f},{r['p95']:.3f}] P(top)={r['p_top']:.2f} conf={r['confidence']}")
```
