Source: UNDP GeoHub, “2016 Soil Salinity map” (dataset d65242be633be3fb99d5519831ea1744)
License: Creative Commons Attribution 4.0 (CC BY 4.0)
Published resolution: 1 km. Model validation accuracy: 67–70%.
This product provides categorical classes, not EC/ECe measurements in dS/m. Never convert these classes to a numeric salinity value.
Class codes: 0=no data, 1=non-saline, 2=slightly saline, 3=moderately saline, 4=highly saline, 5=extremely saline.
Original dataset: https://geohub.data.undp.org/data/d65242be633be3fb99d5519831ea1744
